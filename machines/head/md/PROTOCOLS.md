The request format is `bio-md-request.v1`. `validate_request` and `prepare` only inspect/copy admitted assets and create a sealed stage graph. The head performs native GROMACS preflight before cloud allocation; the worker executes the same graph with its pinned runtime. Every stage declares its dependencies, input/output files and native checkpoint. Coordinates, topologies, manifests, logs, native trajectories, energy files, PMFs and final PDBs are retained.

The JSON files in `examples/` show the required shape. Paths, selections, mutations, CV atom indices and settings must be replaced for the actual construct. Their simulation durations are illustrative and do not establish convergence. An optional `comparison_id` identifies the same target/transformation across force-field studies; without one, the request hash isolates comparisons. `model_id` is a label, while conditions and topology/parameter hashes identify the Hamiltonian.

All routes require already prepared, solvated and ionized GROMACS coordinates and topology. Supply the actual force-field name, water model, salt concentration, temperature, pressure, protonation method/pH/review, and the force field's electrostatic/Lennard-Jones settings. The pipeline never silently selects protonation or modifies an amidite. Topology includes must remain inside admitted assets or reference the declared installed force field. `grompp` warnings are not overridden.

For modified DNA/RNA, each system accepts `parameter_manifests: ["chemistry/residue-a.json", "chemistry/residue-b.json"]`; `parameter_manifest` remains a singular alias. The incorporated residue needs the `bio-md-residue-parameters.v1` chemical graph and SHA-pinned GROMACS parameters described by `chemistry.py`, including explicit hydrogens, stereochemistry and external linkages. Runtime admission checks every custom residue against the processed topology. Unknown residues without a manifest are rejected. A parameter match records identity and incorporation; it does not establish experimental accuracy.

`pmx_binding_ddg` runs paired bound and unbound A→B transformations, each with independently initialized replicas and independently equilibrated lambda windows. Prepared pmx hybrid topologies are accepted directly. The `generate` mode requires a complete prepared PDB retaining chain/residue identity and explicit confirmation of pdb2gmx protonation; it invokes `pmx mutate`, `gmx pdb2gmx`, and `pmx gentop`. GROMACS-generated absolute force-field includes are made portable only when they resolve inside the declared pinned library. Standard protein substitutions are supported; arbitrary custom-residue mutations are not. Declared and actual net-charge changes are rejected because no finite-size charge correction has been implemented.

Each lambda window performs minimization, NVT equilibration, NPT equilibration and NPT production. `calc-lambda-neighbors=-1` retains all-state reduced energies in DHDL output. Automatic analysis parses native XVG with alchemlyb, decorrelates samples, evaluates MBAR and adjacent BAR, and reports overlap/effective samples/time stability. It computes ΔΔG_bind = ΔG_bound − ΔG_unbound with the original transformation direction; positive values weaken binding in that model. Unsupported overlap yields an explicit unavailable cycle while retaining leg diagnostics. Independent replicas are combined only within the same Hamiltonian; model disagreement remains visible.

`plumed_metadynamics` accepts one or two explicit distance/torsion CVs and atom ranges for whole-molecule reconstruction. It runs well-tempered metadynamics through the real GROMACS/PLUMED interface (`-ntmpi 1`). Raw shell/PLUMED includes, ENERGY CVs and replica exchange are not admitted. HILLS and COLVAR are retained for checkpoint restart. The final analysis recomputes a binned free-energy surface from the full retained COLVAR using `REWEIGHT_METAD` log weights; it preserves the original sample when native PLUMED reprints one identical-coordinate checkpoint time after a new FIELDS header, records that discard, and rejects other overlapping restart times or samples outside the grid. Only this final `reweighted-fes.dat` is produced: periodic online histogram/FES writes were redundant and exhausted PLUMED's file-backup limit on long runs. The simulation still records the metadynamics bias, normalized bias, reweighting factor and log weights at every requested output stride. Unsampled bins remain `inf`. Its importance-weight ESS does not account for time correlation. This is a CV surface, not a binding-affinity estimate or proof of construct function.

`bfee3_geometric` uses upstream BFEE3's GROMACS generator and postTreatment analysis (the Python namespace remains `BFEE2`). Supply separate bound/unbound systems, receptor/ligand/solvent selections, and optionally a separate unbound ligand selection. Selected ligand heavy-atom names/residues/order must match across systems. Receptor and ligand must occupy separate topology molecular instances and provide noncollinear orientational anchors. These requirements also apply to DNA/RNA partners; custom residues additionally need their manifests.

BFEE3 first equilibrates the supplied systems. Its upstream generator normally estimates a new cell and offers distance-leg scripts that re-solvate the system. This integration restores the actual prepared positions and box before generating upstream restraints and uses explicit GROMACS stages throughout, preserving solvent/ion counts. Biased PMFs use fixed-volume NVT. The orthorhombic box must accommodate the requested bulk distance, both partner radii and the explicit periodic-image margin. If it cannot, preparation fails instead of silently diluting the system. Restraint centers use measured prior PMF minima before GROMACS embeds the Colvars configuration in each TPR. Zero-filled unsampled PMF bins are not accepted as minima: the current conservative admission gate requires actual physical-CV counts of at least the upstream FullSamples threshold (10,000) in every bin and an interior minimum. Insufficient coverage stops subsequent restraint stages; it requires additional sampling/range review, not an invented center. All eight PMFs are required; flexible partners are not relabelled rigid to omit terms. Raw upstream geometric standard-state contributions are retained in kcal/mol. The reported affinity remains unavailable when physical-CV count coverage is insufficient; otherwise a conditional estimate is also converted to kJ/mol, with no invented uncertainty or convergence claim. The bulk plateau and PMF histories still require scientific review and independent repeats.

Native restarts retain GROMACS checkpoints and bias histories. GROMACS 2026.3 informs PLUMED of a checkpoint restart and requests PLUMED checkpoint writes; completed stages are skipped only when their inputs and outputs still match their receipts. Source coordinates remain available alongside each stage's actual final PDB. A successful short engine test establishes toolchain execution only; it does not validate the force field or establish affinity accuracy.
